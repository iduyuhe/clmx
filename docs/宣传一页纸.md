# CLMX 融合型 AI 平台

## 一页看懂 · 2026

---

**定位**: 工业设备预防性维修平台 + NLP/ML 模型平台 → SaaS 交付

---

## 一句话

> **设备的 AI 大脑。从传感器到模型，从模型到决策，开箱即用。**

CLMX 是一套融合型 AI 平台：把工厂设备的遥测数据吃进来，用机器学习训练出异常检测模型，实时算出健康分、推送预警——同时还能做中文文本分类（情感分析/工单分类）。一套系统，两个引擎，SaaS 租给你。

## 核心能力

### ⚙️ 设备预防性维修
- 三种设备接入：**MQTT**（自托管 Broker, :1883）/ **HTTP 推送** / **OPC-UA**
- **时序异常检测**：无监督学习，零标注，自动学习设备正常特征
- **混合健康评分**：规则引擎 + ML 模型加权计算，0-100 分
- **预警自动投递**：站内信 + Webhook + 企业微信机器人

### 🧠 NLP · ML 模型平台
- **中文文本分类**：零依赖朴素贝叶斯，不联网、训推同构（Python 训练 → 纯 JS 推理）
- **100 条样本**即可训练出可用的情感/工单分类模型
- 支持自定义数据集（JSONL 格式）、版本管理、全流程追溯

### ☁️ SaaS 多租户
- **行级隔离**：PostgreSQL tenantId 过滤，数据绝对不串
- **四级 RBAC**：管理员 / 管理者 / 标注员 / 观察者
- **配额熔断**：存储超限、API 超量自动阻断（HTTP 429）
- **品牌白标**：Logo、主色、域名、Favicon，租户完全独立品牌
- **用量看板**：实时监控 + CSV 导出
