# 路线图 · Roadmap

CLMX 以「融合型 AI 平台」为定位：以工业设备预防性维修为外壳，NLP/ML 模型平台为底座，SaaS 多租户交付，并叠加 AI 原生接入生成器与北向 MCP 能力开放。

## 已落地（v0.1.0）

| 阶段 | 能力 | 状态 |
|------|------|------|
| 阶段0 | 规则引擎（健康分 / 告警） | ✅ |
| 阶段1 | 数据积累与标注 | ✅ |
| 阶段2 | 工业时序 ML 管线（无监督异常检测） | ✅ |
| 阶段3 | SaaS 化（多租户行级隔离 + PostgreSQL） | ✅ |
| 阶段4 | 增值（配额/计费/白标）+ 真实设备接入（MQTT） | ✅ |
| 阶段5 | AI 原生接入生成器（文档 → 物模型 + 驱动 + 自测 + 复用） | ✅ |
| 阶段6 | 北向 MCP 能力底座（零依赖 stdio Server，10 工具） | ✅ |
| 阶段7 | 能力资产化治理（接入资产市场 + 一键复用） | ✅ |

## 进行中 / 规划

- 半智能体闭环深化：异常自动处置工单与训练结果自动解读的联动
- 零依赖边缘 JS 推理扩面（更多垂类模型同构训推）
- 北向 MCP 工具集扩充与权限模型细化
- 远端 GPU 训练 / 推理调度稳定性
- 可视化运营看板与多租户自助开通

> 方向受 HubPort「AI 原生物联网平台」思想启发（融思想、不搬产品）：原生接入、创建时 AI / 运行时零 AI、能力资产化、北向开放。详见 `docs/HubPort思想融合规划.md`。
