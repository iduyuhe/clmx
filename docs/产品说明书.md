# CLMX 融合型 AI 平台 · 产品说明书

> **版本**: v1.0 | **更新**: 2026-07-15

---

## 一、产品定位

CLMX 是一套**融合型 AI 平台**——以工业设备预防性维修为前端场景，以 NLP/ML 模型平台为技术底座，以 SaaS 多租户为交付模式。面向制造企业及 AI 服务商，提供从数据采集、模型训练到推理部署的完整闭环。

## 三、功能矩阵

### 3.1 设备预防性维修（工业外壳）

| 模块 | 功能 | 说明 |
|------|------|------|
| **设备管理** | 台账 CRUD / 传感器配置 / 分类与标签 | 管理工厂设备全生命周期 |
| **时序数据摄入** | MQTT 自托管 Broker / HTTP 推送 / OPC-UA | 三种协议覆盖不同现场条件 |
| **实时监控** | 传感器实时数值 / 历史趋势 / 数据回放 | 秒级刷新，大屏看板 |
| **时序训练** | 无监督异常检测（Autoencoder / 隔离森林） | 零标注，自动学习设备特征 |
| **健康评分** | 规则引擎 + ML 异常分混合计算 | 0-100 分，支持阈值预警 |
| **预警推送** | 站内信 / Webhook / 企业微信机器人 | 健康分 < 60 自动触发 |
| **维修工单** | 工单创建 / 派发 / 跟踪 / 备件管理 | 与健康分联动 |
| **演示数据** | 一键生成仿真设备 + 遥测 + 健康分 | 开箱即可演示 |

### 3.2 NLP/ML 模型平台（技术底座）

| 模块 | 功能 | 说明 |
|------|------|------|
| **中文文本分类** | 零依赖朴素贝叶斯，训推同构 | 不联网、20 样本即可训练，纯标准库 |
| **训练引擎** | Python worker (child_process) | CPU 模式，适配 2G 内存 |
| **推理引擎** | 纯 JS 实现，读取 JSON 模型 | 零外部依赖，与 Python 训练端算法一致 |
| **预训练推理** | Transformers.js (ONNX) | 情感分析 / NER / 摘要等 NLP 任务 |
| **模型版本管理** | 训练产物 → ModelVersion → checkpoint | 可追溯、可回滚 |
| **数据集管理** | CSV / JSONL / 标注 / 版本化 | 带标注工作流 |
| **演示数据集** | 100 条正负情感分析样本 | 一键生成，快速验证 |

### 3.3 SaaS 多租户交付

| 模块 | 功能 | 说明 |
|------|------|------|
| **多租户隔离** | PostgreSQL 行级 tenantId | 数据绝对隔离 |
| **RBAC 权限** | ADMIN / MANAGER / ANNOTATOR / VIEWER | 四级角色 |
| **配额管理** | 存储限额 / API 调用限额 / 熔断 | 按套餐配置 |
| **套餐目录** | TRIAL / FREE / PRO / ENTERPRISE | 自助升降级 |
| **品牌白标** | 公司名 / Logo / 主色 / Favicon / 自定义域名 | 租户级独立品牌 |
| **用量看板** | 近 7 日趋势 / 调用明细 / CSV 导出 | 实时监控 |
| **计费账单** | 月结生成 / 模拟支付 | 支持导出 |
| **审计日志** | 操作全记录 / 筛选搜索 | 合规审计 |

## 五、快速开始

### 注册
访问 `http://<host>:3003` → 注册账号 → 选择套餐（TRIAL/FREE/PRO）。

### 演示数据
登录后 → 设置 → 演示数据 → 选择规模（小/中/大）→ 生成。

演示数据包含：设备、传感器、遥测数据、健康分、告警规则、维修工单、NLP 情感分析样本。

### 中文文本分类快速体验
1. 运行演示数据生成（自动创建 `DEMO-中文情感分析模型`）
2. 进入「模型管理」→ 找到该模型 →「发起训练」
3. 选择演示数据集 → 开始训练（< 10 秒）
4. 进入「模型推理」→ 切换「我的训练模型」→ 选择版本 → 输入中文评论文本 → 查看分类结果

### 工业时序异常检测
1. 演示数据生成 → 产生传感器遥测数据
2. 进入「数据管理」→ 用 `sensor-data` 窗口化创建一个时序数据集
3. 创建工业模型 → 时序训练（数据量足够时自动启用无监督异常检测）
4. 健康评分自动接入训练模型 → 健康分动态变化 → 告警自动推送
